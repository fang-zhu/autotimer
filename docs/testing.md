## 核心用例

- 回答文字暂停但停止按钮还在：不会完成。
- 停止按钮暂时消失但没有本轮回复操作按钮：不会完成。
- 回复变化、离线、错误、输入框禁用或出现草稿：清空稳定计时。
- 只有旧回答或旧的相同提示词：不当作新一轮成功。
- 点击意图在点击前已写到磁盘；点击返回异常不再次点击。
- 点击后崩溃再载入状态：核对发送，不调用 prepare 或 click_send。
- 连续两个相同提示词：各发送一次，并等待各自回答。
- 多余人工用户消息或发送前对话变化：暂停。
- 刷新页面、替换输入框 DOM、备用选择器：重新定位并完成核对。
- Chromium 关闭再使用同一持久化目录打开：本地页面历史仍可核对。
- 网络断开后恢复：离线时不能判定完成，恢复后重新观察。
- 回答超时：生成截图；即使 continue_on_error 为 true，无法确认本轮结束也不发送下一步。
- 两个实例争用同一登录目录：第二个被拒绝；释放后可重新运行。
- 修改日志目录：仍从登录目录中的索引找到未完成任务。
- 断点损坏或索引对应文件丢失：阻止启动新任务。
- 任务抛出异常或浏览器启动失败：关闭 context / Playwright 引擎。
- 日期跨午夜、开始时间已过、立即运行、50 个步骤、中文路径与提示词、配置字段拼写错误。

开发中发现并修复了 Windows 文件锁在加锁区域读取时先触发 PermissionError 的问题；回归测试覆盖了这一情形。另修正了恢复阶段不应先等待当前回答结束才开始监控，以及管道输出中文编码问题。
