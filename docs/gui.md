# Windows 桌面版使用说明

双击 `D:\autotimer\start_gui.bat`，或运行：

从 GitHub 首次下载时，先按 README 安装依赖，并将 `config.example.yaml` 复制为 `config.yaml`。仓库不会提供你的个人配置和登录状态。

```powershell
cd D:\autotimer
.venv\Scripts\python.exe gui.py
```

打开窗口不会自动发送。填写对话链接、开始时间（例如 `2026-09-08 08:30:00`），或勾选“立即执行”；编辑提示词后点击“启动任务”。启动前会验证并保存配置。

## 窗口操作

- **提示词步骤**：添加、删除、上下排序，直接编辑内容，或导入单个 TXT。步骤 ID 在排序时保持不变。
- **TXT 自动分步导入**：按“第一、第二”拆分，先预览，再选择追加或替换；不会改写原 TXT。
- **浏览器与登录**：选择程序专用窗口，或连接开启本机调试端口的 Chrome/Edge。
- **等待与异常设置**：修改超时、重试、步骤间隔和路径。
- **停止任务**：请求停止自动操作并保存断点，等待浏览器资源处理完成后才能再次启动。它不等于停止 ChatGPT 服务器生成。
- **打开日志**：打开本次任务日志目录；未运行时打开配置的日志根目录。

运行期间设置锁定，日志和进度持续更新。再次启动发现未完成任务时弹窗选择恢复、从头重跑或取消；重跑还须输入 `RESTART`。退出前会提示保存未保存的修改，运行中退出会先停止任务。

窗口保存配置前自动保留上一版 `config.yaml.bak`，保存后的 YAML 注释和排版可能变化。外置 TXT 未编辑时保留文件引用；在窗口里改动其内容后，改动会写入 YAML 的 `prompt` 字段，原 TXT 保持不变。如果外置文件在窗口打开后被其他软件修改，会要求重新读取，避免显示内容和实际发送内容不同。

本地开发时的旧版备份保存在 `backups/`，不上传 GitHub；从 GitHub 下载不会获得这些本机备份。

## TXT 根据“第一、第二”自动分步

点击提示词列表下的 **“TXT 自动分步导入…”**，选择 UTF-8 文本文件。例如：

```text
第一步：分析问题
请分析这个问题，列出关键因素。

第二步：进一步细化
根据上一轮回答，提出三个具体方案。

第三步：整理结果
把上面的方案整理成表格。
```

也支持 `第一、请分析…`、`第二、请总结…`，以及单独一行的 `第一`、`第二`。每个标题必须另起一行，从第一开始连续编号。正文中的“第一次”不会当作分步标题，代码块内的编号也不会拆开。没有标题时按一条提示词导入；重复/跳号会提示检查。标题和正文都保留，第一步之前的说明并入第一步。

在预览窗口检查每步内容，然后选择“追加到现有步骤”或“替换现有步骤”，最后保存配置。导入不会发送内容。示例文件：`prompts/分步示例.txt`。

## 连接已经打开的 Chrome / Edge

普通方式打开的浏览器没有对外提供控制接口，不能直接接管其标签页。连接模式需要启用 **本机远程调试端口**，即只供本机程序控制这个浏览器的接口。

1. 在“浏览器与登录”页选择 **“连接已打开的浏览器”**，选择 Chrome 或 Edge。
2. 保持连接地址 `http://127.0.0.1:9222`，点击 **“打开可连接浏览器（先手动登录）”**。
3. 在新开的 Chrome/Edge 窗口中本人手动登录，并打开配置的对话。只保留一个目标对话标签。
4. 回到程序点击“启动任务”。连接模式不会新建或重载标签，只选择已经打开的目标对话。
5. 停止或完成后程序只断开连接，浏览器继续保留。以后窗口还开着时直接启动任务；窗口关闭后再次点“打开可连接浏览器”即可复用登录数据。

该按钮使用 `browser_data/connected/chrome/` 或 `browser_data/connected/msedge/` 独立目录。**它不会复制你日常浏览器的登录数据，因此首次仍可能需要登录**。已有使用专门配置目录、开启本机调试端口的浏览器时，可直接填写其本机端口连接，不必重复点击打开按钮。

仅接受 `127.0.0.1` 或 `localhost` 地址，勿将端口开放到网络。端口已经占用时按钮会提示；如果该浏览器已经打开，在其中登录后直接启动即可。普通浏览器窗口不能通过事后勾选一个选项变为可连接窗口。

手动完成人机验证后仍反复验证时，程序不能绕过，也不能保证连接模式解决。请先停止自动任务，确认该 Chrome/Edge 窗口本身能正常手动访问 ChatGPT；未通过网站验证前不要启动自动发送。程序不自动点击验证、修改浏览器指纹或关闭安全检查。

对应 YAML 配置如下，未设置 `mode` 时仍保持旧的专用窗口模式：

```yaml
browser:
  mode: cdp
  channel: chrome       # 或 msedge
  cdp_url: "http://127.0.0.1:9222"
  headless: false
  use_persistent_profile: true
  profile_dir: "browser_data"
```

同一任务切换连接方式不改变提示词和对话的指纹，仍能从旧断点核对恢复。不要更换步骤内容或删除断点来处理人机验证。恢复时看到全部步骤为“等待”，表示尚未发送。

## 验证边界

程序的单元、窗口组件和本地浏览器测试不使用真实账号，不代表 ChatGPT 已允许自动操作。桌面截图检查曾因电脑控制工具的应用授权超时未完成，已通过原生窗口组件测试检查编辑、锁定和状态更新。真实 ChatGPT 的登录、当前页面兼容性及验证循环是否消失，仍须你本人验收。
